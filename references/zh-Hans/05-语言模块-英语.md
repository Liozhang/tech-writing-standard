# 05 语言模块：英语（en，1.2 正式版）

本文件规定英语技术文档的具体写法，分普通变体与高安全变体。普通变体供一般文档使用；高安全变体供完整级符合性的文档使用，以 ASD-STE100 为依据。选择哪一档在文档元数据中声明。

## 一、普通变体

EN-001（应该）句长以词数度量：操作类单句不超过 20 词，描述类不超过 25 词。来源：参考 ASD-STE100 上限，普通变体作为建议执行。理由：超出该长度后读者回读率显著上升。企业风格指南未设此限，组织可按需调整，但须全文档集统一。

EN-002（必须）一句一意；一句一条指令；一段一个主题，每段不超过六句。来源：ASD-STE100。

EN-003（必须）使用主动语态；描述性内容仅在动作发出者不明时使用被动语态。来源：ASD-STE100。

EN-004（必须）术语全文统一，同义词不混用；缩写首次出现给全称。

EN-005（必须）标点、大小写、串行逗号、界面元素写法、代码写法按下列方式确定：文档集指定一份主指南（微软或谷歌出版写作风格指南二选一），其他事项以书面决定登记表裁定，登记表未覆盖的以主指南为准，主指南也未覆盖的以《芝加哥手册》兜底。禁止混用两套指南且不登记。来源：企业风格指南实践。理由：两家指南在串行逗号、缩约形式等处相反，不指定仲裁人则团队遇分歧即停滞。

EN-006（必须）拼写参数在模块内二选一：en-US 美式拼写或 en-GB 英式拼写；拼写分歧词形交术语库登记，不另设语言模块。理由：拼写是地域变体，不是语言变体，另设模块违反地域参数化原则。

EN-007（必须）不使用俚语、习语、幽默和文化典故。来源：与 GEN-046 一致，通用层已规定，本处不再重复。

EN-008（必须）日期写法遵循 GEN-050；出于阅读习惯可并列本地格式，以数字格式为准。

EN-009（必须）句长计数规则：按空格分词；连字符连接的复合词计一词；缩写与首字母缩略词计一词；标题、代码块不计入正文句长。理由：计数规则缺失则工具无法自动检查。

EN-010（应该）第二人称称呼读者，礼貌基调全文档集统一。

## 二、高安全变体（ASD-STE100）

以下规则仅在选择高安全变体时生效，来源为 ASD-STE100 现行版本。本变体是其词汇与句式控制的执行层，不替代 ASD-STE100 本身，也不替代合同与客户规范。

EN-100（必须）本变体覆盖 ASD-STE100 的三类写作规则：程序（步骤文）、描述（描述文）、警告（安全警示）三部分，以及标点、从句、连接词的限制，逐条执行，不得只执行词汇部分。理由：只摘录词汇规则而漏句式规则，是常见的不完整执行。

EN-101（必须）词汇只允许使用 ASD-STE100 词典中的批准词，且只按词典规定的词性和含义使用。

EN-102（必须）批准词表之外的技术名词、多词名词、技术动词，按 ASD-STE100 的认定规则确认后方可使用；项目技术名词表须经客户书面批准，批准清单随文档集维护。理由：词表失控会导致变体失效。

EN-103（应该）多词名词不超过三个词；确因行业惯例需要更长的复合名词时，登记豁免。以 ASD-STE100 规则原文为准，本文为摘要。

EN-104（必须）动词形态只使用不定式、祈使式、一般现在时、一般过去时、一般将来时五种；过去分词仅作形容词用；不使用助动词构成复杂结构。来源：ASD-STE100。

EN-105（必须）不为缩短行文省略句子成分；主语、动词、冠词不得省略。

EN-106（必须）安全警示以命令或条件开头，句式遵循 GEN-022 与 GEN-023。

EN-107（必须）本变体不得单独使用，须同时满足本规范其余部分、合同引用的客户规范和适用地区的强制要求。来源：ASD-STE100 官方声明其不能单独使用。理由：官方明确声明；本规范不重复“把受控语言当风格指南误用”的历史教训。

## 三、本地化参数表

| 参数 | 普通变体 | 高安全变体 |
|---|---|---|
| 句长度量单位 | 词（计数规则见 EN-009） | 词 |
| 操作类句长上限 | 20 词 | 20 词 |
| 描述类句长上限 | 25 词 | 25 词 |
| 文字方向 | 从左向右 | 从左向右 |
| 拼写参数 | en-US 或 en-GB，二选一 | 按合同规定 |
| 词汇控制 | 主指南加书面决定登记表 | ASD-STE100 批准词表 |
| 动词形态 | 按主指南 | 五种形态限制 |
| 日期格式 | 依 GEN-050 | 依 GEN-050 |
| 译文长度余量 | 待实测填写 | 待实测填写 |
