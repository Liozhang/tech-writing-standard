# 11 标准映射矩阵（1.2 正式版）

本文件登记本规范各组成部分与来源标准的对应关系，用于核对引用完整性，也作为母标准换版时的对照清单。引用文件采用不注日期引用，以最新版本为准，版本核对义务由维护组承担（见总纲第九条）。

## 一、组成部分与上位来源

| 本规范组成部分 | 主要来源 | 关系 |
|---|---|---|
| 总纲五项原则 | ISO 24495-1:2023（前四项） | 直接采用，第五项本规范增设 |
| 符合性等级与评定程序 | GB/T 1.1 体例惯例与认证实践 | 本规范自定 |
| 通用规则的信息类型 | DITA 三类模型，教程与排障两类取业界四分类实践 | 扩展采用 |

| 通用规则的安全警示 | ASD-STE100 警示规则；IEC/IEEE 82079-1 | 句式合并 |
| 能量隔离条款 | 机械行业安全惯例；ISO 12100 | 通用化提升 |

| 规范 | 状态与原因 |
|---|---|
| Attempto 受控英语 | 不采用：可读性差，只适合机器可读的规格说明 |

| GB/T 7714 | 资料性引用：只用于科研参考文献著录，同上 |

## 五、换版对照清单

母标准发生以下变化时，须启动对照修订：ISO 24495-1 换版；ASD-STE100 换版；IEC/IEEE 82079-1 换版；DITA 换版；WCAG 换版；GB/T 15834、GB/T 15835、GB/T 16159、GB/T 1.1、GB/T 7713、GB/T 7714 修订；ISO 13485、ISO 12100、ISO 15223-1、ISO/IEC 62366-1、ISO 30042、ISO 17100 换版；欧盟机械法规、欧盟医疗器械法规、体外诊断法规、21 CFR 相关部分更新；Unicode CLDR 主版本更新。
